

1# What is the difference between var, let, and const?

Ans: var → Old way to declare variables. It can be re-declared and updated.

let → Modern variable. It can be updated but cannot be re-declared in the same scope.

const → Constant variable. It cannot be updated or re-declared.

2# What is the spread operator (...)?

Ans: The spread operator ... is used to expand or copy elements of an array or object.


3# What is the difference between map(), filter(), and forEach()?

Ans: map() → Creates a new array by changing each element.

filter() → Creates a new array with elements that match a condition.

forEach() → Loops through the array but does not return a new array.
